Contrôle

quand démarré (when started)

Description Les blocs coiffés (hat blocks) font partie d'un groupe de blocs de contrôle qui commencent à s'exécuter lorsque l'icône de DÉMARRAGE (START) est cliquée. Ces blocs coiffés surveillent diverses conditions illustrées dans leur libellé. Celui-ci s'active spécifiquement lorsque la condition de démarrage du programme devient vraie. D'autres vérifient l'état des boutons ou des conditions booléennes pour qu'elles deviennent vraies avant d'exécuter les blocs placés en dessous d'eux.
Exemple Exemple simple pour détecter une condition de démarrage de programme.

quand le bouton est pressé (when button pressed)

Description Ce bloc coiffeur (hat block) surveille l'état des boutons du micro-appareil et exécute le code placé en dessous lorsqu'un des boutons de l'appareil est pressé.
Il se déclenche une fois pour chaque pression de bouton. Si vous maintenez le bouton enfoncé, il ne se redéclenche pas tant que vous ne relâchez pas le bouton pour le presser à nouveau.
Remarque : tous les micro-appareils n'ont pas de boutons. Votre code peut ne pas s'exécuter correctement selon l'appareil cible.
Exemple L'état du bouton B est surveillé, et lorsqu'il est pressé, la lettre B est affichée sur le panneau LED.

pour toujours (forever)

Description Les blocs en forme de C font partie d'un groupe de blocs de contrôle qui exécutent le code placé à l'intérieur tant que les conditions décrites dans leur libellé sont vraies. On les appelle aussi blocs de BOUCLE (LOOP). Celui-ci exécutera les blocs à l'intérieur indéfiniment. Couramment utilisé pour tracer des valeurs ou surveiller en continu les valeurs de ports, etc.
Exemple Le programme énonce et fait défiler la température mesurée par le micro-appareil.
