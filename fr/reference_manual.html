Référence des blocs (Blocks Reference)

Descriptions succinctes de tous les blocs disponibles dans la palette.
Astuce : Dans toutes les sections « Plus de détails et exemples » du wiki officiel, vous pouvez glisser-déposer directement les blocs d'exemple vers la zone de scripts de l'IDE MicroBlocks pour les copier et les exécuter immédiatement.

  • Allume ou éteint la LED utilisateur. Sur le micro:bit (et les cartes qui simulent un affichage micro:bit), la LED utilisateur se trouve au centre de la première ligne de l'affichage.
  • Affiche une bulle contenant la ou les valeurs indiquées.
  • Trace la ou les valeurs données dans le panneau d'affichage des graphiques de données.
  • Efface les valeurs tracées sur le graphique.

  • Renvoie le nombre de millisecondes écoulées depuis la dernière réinitialisation du chronomètre, puis remet le chronomètre à zéro (les blocs millisecondes et microsecondes ne sont pas affectés).
  • Renvoie les secondes écoulées depuis la mise sous tension ou la réinitialisation matérielle de la carte.
  • Renvoie les millisecondes écoulées depuis la mise sous tension ou la réinitialisation matérielle de la carte.
  • Renvoie les microsecondes écoulées depuis la mise sous tension ou la réinitialisation matérielle de la carte.
  • Renvoie le type de cet appareil (ex: micro:bit, ESP32 ou Clue).

  • Renvoie l'identifiant BLE à 3 lettres du microcontrôleur.
  • Renvoie les millisecondes écoulées depuis un temps de référence donné.
  • Renvoie les microsecondes écoulées depuis un temps de référence donné.

Broches (Pins)

  • Renvoie la valeur (vrai ou faux) d'une broche numérique donnée.
  • Renvoie la valeur (0 - 1023) d'une broche analogique donnée.
  • Définit la valeur (vrai ou faux) d'une broche numérique donnée.

  • Renvoie le nombre total de broches numériques prises en charge par cet appareil.

Communication (Comm)

La catégorie Comm contient des blocs pour communiquer avec des périphériques matériels via un bus I2C (Inter-Integrated Circuit), SPI (Serial Peripheral Interface) ou le port série UART. Ces blocs avancés sont généralement utilisés par des personnes expérimentées pour créer des bibliothèques destinées à des capteurs ou au kit robotique Hummingbird:bit.

Pour utiliser ces blocs, vous devez consulter la fiche technique (datasheet) du matériel concerné. De nombreux appareils I2C et SPI doivent être configurés ou activés avant utilisation. Il est souvent utile d'étudier le code source d'une bibliothèque existante.

Remarque : La catégorie Comm n'est visible que lorsque l'option « afficher les blocs avancés » a été activée.

Avancé

  • Renvoie la valeur d'un registre donné (0-255) d'un appareil I2C (0-127).
  • Écrit un octet (0-255) sur un appareil I2C et un registre donnés.
  • Reçoit plusieurs octets d'un appareil I2C donné.
  • Envoie plusieurs octets à un appareil I2C donné.
  • Envoie un octet à un appareil SPI.
  • Lit un octet d'un appareil SPI tout en envoyant un octet nul, et renvoie l'octet reçu.
  • Ouvre le port série à la vitesse (baud rate) spécifiée.
  • Ferme le port série.
  • Reçoit plusieurs octets du port série.
  • Envoie plusieurs octets sur le port série.
  • Envoie plusieurs octets sur le port série à partir d'un octet sélectionné.
  • Envoie un octet au port série logiciel (softSerial).
  • Reçoit plusieurs octets d'un appareil Duelink (sous forme de tableau d'octets).
  • Envoie plusieurs octets à l'appareil Duelink à partir d'un octet sélectionné.

Contrôle (Control)

  • quand démarré : Les blocs placés sous ce chapeau s'exécutent à la mise sous tension ou lorsque l'icône verte DÉMARRAGE est cliquée.
  • quand le bouton est pressé : S'exécute lorsque les boutons A, B ou A+B sont pressés.
  • répéter indéfiniment (forever) : Boucle en C qui s'exécute en continu, indéfiniment.
  • répéter (repeat) : Boucle en C qui s'exécute un nombre de fois spécifié.
  • attendre millisecondes : Fait une pause du nombre de millisecondes indiqué avant de continuer.
  • si (if) : Exécute les blocs internes uniquement si la condition est vraie.
  • quand (when) : S'exécute dès que la condition spécifiée devient vraie.
  • attendre jusqu'à ce que (wait until) : Met en pause l'exécution jusqu'à ce que la condition devienne vraie.
  • retourner (return) : Starrête l'exécution du script et renvoie la valeur indiquée comme résultat.
  • quand le message est reçu : S'exécute lorsqu'un message du nom spécifié est diffusé.
  • envoyer le message (broadcast) : Diffuse le message spécifié.
  • commentaire : Ne fait rien en soi ; sert à ajouter des notes et de la documentation.
  • intervalle (range) : Utilisé pour définir une plage de paramètres dans la boucle POUR.
  • pour (for) : Boucle en C qui s'exécute un nombre de fois donné, en affectant à une variable le numéro d'itération.
  • répéter jusqu'à ce que (repeat until) : Boucle en C qui tourne jusqu'à ce que la condition devienne vraie.
  • arrêter cette tâche : Arrête l'exécution du script dans lequel il se trouve.
  • arrêter les autres tâches : Stoppe tous les autres scripts en cours, tandis que le script actuel continue de tourner.

Avancé

  • attendre microsecondes : Pause pour un nombre précis de microsecondes.
  • dernier message : Renvoie le dernier message reçu suite à un bloc de diffusion.
  • arg : Renvoie la valeur de l'argument de fonction sélectionné.
  • appeler la commande personnalisée : Appelle un bloc personnalisé (fonction) avec éventuellement une liste de paramètres.
  • appeler le rapporteur personnalisé : Appelle une fonction personnalisée et renvoie son résultat.

  • Renvoie la somme des arguments.
  • Comparaisons : inférieur, inférieur ou égal, égal, différent, supérieur ou égal, supérieur.
  • Constante booléenne (vrai / faux).
  • Inverse logique (NON).
  • ET logique, OU logique.
  • Conversion en chaîne de caractères (String).
  • Vérification du type de données.

    • Avancé

  • Opérateur conditionnel (si ... alors ... sinon ...).
  • Mise à l'échelle (scale) d'une valeur d'une plage vers une autre.
